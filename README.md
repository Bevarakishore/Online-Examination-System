✨ Project Overview

Testify is a modern web-based examination platform designed to provide an interactive and user-friendly environment for online assessments. It combines examination management functionality with futuristic visuals and 3D animations to deliver an engaging digital experience.

⚡ Core Features

- 🔐 Separate student and administrator login interfaces
- 🎓 Student identification using hall ticket and academic details
- ⏱️ Countdown timer and automatic exam submission
- 📝 Multiple-choice questions and question navigation
- 📊 Automated scoring and result display
- 📂 Examination document upload interface
- 👨‍💻 Administrator dashboard for student status
- 🌌 Interactive 3D graphics using Three.js
- 📱 Responsive user interface

🛠️ Technology Stack

Technology| Application
